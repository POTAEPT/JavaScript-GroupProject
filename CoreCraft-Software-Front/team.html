Meet Our Experts

ทีมงานผู้เชี่ยวชาญมากประสบการณ์ของเรา พร้อมนำความรู้และความเชี่ยวชาญที่สั่งสมมาหลายทศวรรษ มาร่วมสร้างสรรค์โซลูชันที่มั่นคงและตอบโจทย์ทุกความท้าทายของธุรกิจ

นาย จิรายุ พรมยวน (โฟว์วิล)

Project Manager (PM) / System Analyst (SA)

บริหารและกำกับระยะเวลาโครงการ รวบรวมและวิเคราะห์ความต้องการของผู้ใช้งาน พร้อมวางสถาปัตยกรรมระบบ POS และ ERP ให้สอดคล้องกับเป้าหมายทางธุรกิจ

นาย ณัฐวุฒิ แร่มี (โปเต้)

Lead Full-Stack Developer / Core Architect

พัฒนาระบบซอฟต์แวร์หลัก ออกแบบโครงสร้าง API และ Microservices พร้อมดูแลประสิทธิภาพและความปลอดภัยของระบบให้มีความเสถียรและรองรับการใช้งานในระดับ Enterprise

นางสาว บุญยาพร แก้วพันธ์ (มินตรา)

UI/UX Designer & Lead Frontend Developer

ออกแบบ Design System ด้วย Tailwind CSS พัฒนาส่วนติดต่อผู้ใช้งานให้สอดคล้องกับ Layout และออกแบบ Responsive Interface เพื่อมอบประสบการณ์การใช้งานที่ราบรื่นในทุกอุปกรณ์
