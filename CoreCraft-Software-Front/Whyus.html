SOFTWARE DESIGN PATTERNS

มาตรฐาน Design Patterns ระดับองค์กร (GoF Patterns)

คลิกเลือกดูตัวอย่างการประยุกต์ใช้ Design Patterns ในระบบของ CoreCraft

Strategy Pattern (ระบบ Payment Gateway)

ใช้สลับวิธีการชำระเงิน (PromptPay, Credit Card, TrueMoney Wallet) แบบ Dynamic โดยไม่ต้องแก้ไขโค้ดประมวลผลหลัก

Financial Switch 
// Strategy Interface & Concrete Implementations
class PaymentProcessor {
  setStrategy(strategy) { this.strategy = strategy; }
  executePayment(amount) { return this.strategy.pay(amount); }
}

const promptPay = { pay: (amt) => `PromptPay QR generated for \${amt} THB` };
const creditCard = { pay: (amt) => `PCI-DSS Credit Card charged \${amt} THB` };

ARCHITECTURAL PATTERNS

สถาปัตยกรรมระบบขั้นสูงที่เราใช้

⚡

Offline-First Sync Pattern

สำหรับระบบ POS ในกรณีเครือข่ายอินเทอร์เน็ตหน้าร้านขัดข้อง ข้อมูลคำสั่งซื้อจะถูกบันทึกลง SQLite ท้องถิ่น และซิงก์ด้วย Background Worker เข้า Kafka ทันทีเมื่อเน็ตกลับมา

🧩

Microservices Architecture

แยกบริการตาม Domain (Auth, Orders, Inventory, Payments) เชื่อมต่อกันด้วย gRPC ความเร็วสูง สามารถ Scale หรือ Update แต่ละ Service ได้โดยไม่ต้องปิดทั้งระบบ

🔄

CQRS Pattern

แยก Read Database และ Write Database ออกจากกัน เพื่อเพิ่มสปีดการอ่านข้อมูลสินค้าและสต็อกอย่างรวดเร็ว โดยไม่ส่งผลกระทบต่อประสิทธิภาพการทำ Transaction เขียนข้อมูล
